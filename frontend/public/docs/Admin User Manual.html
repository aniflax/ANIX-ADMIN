Chapter 1

Overview & Role Hierarchy

Welcome to the Admin User Manual for anix HRMS — the comprehensive Human Resource Management System built exclusively for the anix family. As an Admin, you hold one of the most powerful roles in the system, with full access to manage accounts, organizational structures, and all administrative functions.

This manual covers everything that Sevak, HOD, and HR roles can do, plus Admin-specific features. Admin inherits the complete capabilities of every lower role, giving you end-to-end control over the HRMS platform.

1.1   Role Hierarchy

anix HRMS follows a clear role-based hierarchy. Each level inherits all permissions from the levels below it:

👤

Sevak

Basic access — self-service for attendance, leaves, profile, and document uploads.

👑

HOD

Team management — approve/reject leaves and swaps for department members.

💼

HR

Organization-wide — leave admin, attendance reports, communications, department management.

🛡

Admin

Full control — account management, lock/unlock, password resets, all HR features.

ⓘ
Note Above Admin sits the SUPER_ADMIN role, which can only be assigned by existing SUPER_ADMIN accounts. Admins cannot create or manage SUPER_ADMIN accounts.

Chapter 6

Account Management

The Account Management module is the core of Admin-specific functionality. It provides a powerful 3-tab interface for managing all user accounts in the system.

The Account Management page — your command center for user accounts

6.1   The 3-Tab Interface

Account Management is organized into three tabs, each serving a distinct purpose:

All Accounts
Locked Accounts
Delete Requests
👥

All Accounts

View and manage every user account in the system. Search, filter, and perform actions on any account.

🔒

Locked Accounts

Quickly see all accounts that have been locked due to failed login attempts. Unlock them with a single click.

🗑

Delete Requests

Review account deletion requests submitted by sevaks. Approve or reject each request.

6.2   Add Account

Admins can create new HR or Admin accounts directly. This is a secure 3-step process involving email OTP verification.

1
Email OTP
2
Verify OTP
3
Enter Details

Step 1: Enter Email & Request OTP

  1. Navigate to Account Management and click “Add Account”.
  2. Enter the email address for the new account.
  3. Click “Send OTP”. A verification code is sent to the email address.

Step 2: Verify OTP

  1. Check the email inbox for the OTP code.
  2. Enter the OTP in the verification field.
  3. Click “Verify” to confirm the email address is valid and accessible.

Step 3: Enter Account Details

  1. Select the Role — choose HR or Admin.
  2. Enter the Account ID (optional — leave blank for auto-generated).
  3. Fill in the sevak’s personal details (name, phone, department, etc.).
  4. Optionally check “Send activation invitation” to email login credentials automatically.
  5. Click “Create Account” to complete the process.
💡
Tip If you check “Send activation invitation”, the new user will receive an email with their login credentials and a link to activate their account. This is the recommended approach for onboarding.
⚠
Important Admin can only create HR or Admin accounts. Sevak accounts are created through the onboarding process. SUPER_ADMIN accounts can only be created by another SUPER_ADMIN.

6.3   Account Actions

For each account in the system, Admin has access to several management actions. These actions are available from the account list or detail view.

👁   View Profile

Open the full profile of any user to view their details, documents, and account information. Available for all roles.

🔒   Lock Account

Immediately restrict a user from logging in. The locked user will see “Account Locked” on login attempts. Cannot be used on SUPER_ADMIN accounts.

🔓   Unlock Account

Restore access to a locked account. The user can then log in with their existing password. Only Admin can unlock accounts — HR does not have this capability.

🔑   Reset Password

Send a password reset email to the user. They will receive instructions to create a new password. This is useful when a user forgets their password or for security purposes.

🗑   Delete Account

Permanently remove an account from the system. Only available for Admin-level accounts — cannot delete SUPER_ADMIN accounts. Sevak accounts are handled through delete requests instead.

6.4   Failed Login Attempts Tracking

The system tracks failed login attempts for every account. This information is displayed in the account list and helps you identify:

  • Brute-force attempts — Multiple failed attempts from the same account may indicate a security concern.
  • Account lockout triggers — Accounts are automatically locked after a configurable number of failed attempts.
  • Last login timestamp — See when the user last successfully accessed the system.
ⓘ
Note The failed login attempts counter resets automatically when the account is unlocked or when a successful login occurs.

6.5   Account Status Indicators

Each account in the management list displays key status information:

Indicator Description
Last Login Shows the date and time of the user’s most recent successful login. Helps track engagement.
Email Verified Indicates whether the user has verified their email address. Unverified emails may miss important notifications.
Account Status Shows whether the account is Active, Locked, or Pending activation.
Failed Attempts Number of consecutive failed login attempts. Displayed prominently when above zero.

6.6   Locked Accounts Tab

The Locked Accounts tab provides a focused view of all accounts that are currently locked. This makes it easy to identify and resolve access issues quickly.

  1. Navigate to Account Management → Locked Accounts tab.
  2. Browse the list of locked accounts. Each entry shows the user’s name, email, and the reason for the lock.
  3. Click “Unlock” next to the account you want to restore.
  4. The account is immediately unlocked. The user can now log in with their existing password.
❗
Only Admin Can Unlock This is a critical security distinction. HR accounts cannot unlock locked accounts. If an HR user needs to unlock an account, they must contact an Admin or SUPER_ADMIN.

6.7   Delete Requests Tab

When HR submits account deletion requests, they appear in the Delete Requests tab for Admin review. The "Requested By" column shows who raised the request.

  1. Navigate to Account Management → Delete Requests tab.
  2. Review each request — the sevak’s name, role, and who requested the deletion are displayed.
  3. Click “Revoke” to cancel the delete request without deleting the account.
  4. Click “Delete Permanently” (SuperAdmin only) to permanently delete the account.
  5. Alternatively, click “Profile” to view the sevak’s full profile before deciding.
⚠
Caution Account deletion is permanent and irreversible. All data associated with the account — profile, documents, attendance history, leave records — will be permanently removed. Review carefully before approving. You can Revoke the request if you change your mind before deletion.
ℹ
Note Activating an account (changing status from INACTIVE to ACTIVE) automatically clears any pending delete request for that account.

Create, edit, and delete departments. Assign HODs and manage the organizational structure.

Chapter 9

Frequently Asked Questions

1 How do I unlock a locked account?
Go to Account Management → Locked Accounts tab. Find the account and click “Unlock”. The sevak can then log in with their existing password. Note: Only Admin can unlock accounts — HR does not have this access.
2 How do I create a new HR account?
Go to Account Management → click “Add Account”. Enter the email, verify via OTP, then select role as “HR” and fill in the details. You can optionally send an activation invitation with login credentials.
3 Can I delete a SUPER_ADMIN account?
No. SUPER_ADMIN accounts can only be managed by another SUPER_ADMIN. Admins cannot lock, unlock, reset passwords for, or delete SUPER_ADMIN accounts.
4 How do I reset someone’s password?
Go to Account Management, find the account, and click “Reset Password”. An email with reset instructions will be sent to the user’s registered email address.
5 What happens when I lock an account?
The user cannot log in until an Admin or SUPER_ADMIN unlocks it. They will see “Account Locked” on login attempts. All existing sessions are also terminated. The account remains locked until you or another Admin explicitly unlocks it.
6 How do I handle delete requests from sevaks?
Go to Account Management → Delete Requests tab. Review each request carefully — check the sevak’s name and who requested the deletion. Click “Revoke” to cancel the request, or “Delete Permanently” (SuperAdmin only) to permanently delete the account. Activating an account automatically clears its delete request.
7 Can I modify leave balances?
Yes, but only during onboarding (activation day), and only once per sevak. This is an HR/Admin capability used to set initial leave balances when a new sevak joins the organization.
8 How do I change a sevak’s default week-off?
Go to Sevak Directory → find the sevak → Edit Profile → modify the default week-off day. This change takes effect immediately for future attendance calculations.
9 My own account got locked. What do I do?
Contact another Admin or SUPER_ADMIN to unlock your account. You cannot unlock your own account for security reasons.
10 How do I send a bulk communication?
Go to Sevak Directory → click “Official Communication” → select recipients (individual sevaks, entire departments, or all sevaks) → compose your message → click “Send”. All selected recipients will receive the notification.
